# Dinesh Sharma — Personal Portfolio

> Personal portfolio website of **Dinesh Sharma** (AI Engineer | Data Scientist), featuring a warm editorial beige aesthetic inspired by `cobiwave/simplefolio`.

Built with React 19, TypeScript, Tailwind CSS, and Framer Motion.

---

## 🌿 Aesthetic & Design Highlights

- **Palette**: Warm paper beige base (`#F4EFE6`), deep espresso brown typography (`#2B2420`), muted earthy terracotta accents (`#C4623E`), and warm taupe borders (`#DDD0BE`).
- **Typography**: Editorial serif headings (`Playfair Display`) paired with clean humanist sans body text (`Inter`).
- **Interactive 3D Perspective Tilt**: Project preview cards feature physics-based 3D tilt tracking cursor motion with smooth spring return (disabled on touch devices & `prefers-reduced-motion`).
- **Simplefolio-Style Alternating Rhythm**: Alternating project layout with text narrative on one side and interactive thumbnail on the other.
